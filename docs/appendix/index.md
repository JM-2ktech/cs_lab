# 부록 🧰

랩 본문에 넣지 않은 것을 모았습니다. **어느 것도 랩 진행에 필요하지 않습니다.** 시간이 남을 때, 또는 나중에 혼자 해볼 몫입니다.

랩에 붙여 두지 않고 따로 모은 이유는 **어디에 끼울지를 그날 정하기 위해서**입니다. 앞선 랩을 끝냈다면 순서에 상관없이 골라 하면 됩니다.

| 부록 | 분 | 먼저 해야 하는 것 | 무엇을 보나 |
|---|---|---|---|
| [내 에이전트를 Copilot Studio로 가져가기](./to-copilot-studio.html) | 10 | [Lab 1](../lab1.html) | 같은 에이전트가 도구를 바꾸면 무엇이 달라지는가 |
| [에이전트 안에서 일어나는 일](./inside-the-agent.html) | 5+10+10 | [Lab 2](../lab2.html) | RAG·인덱싱 · 토큰과 비용 · 문서가 답을 정한다 |
| [모델을 바꾸면 같은 지침이 다르게 지켜진다](./model.html) | 20 | [Lab 2](../lab2.html) | 지침은 같은데 답이 갈린다. 근거 표시가 거짓인 경우 |
| [채널로 내보내기 — M365 Copilot · Teams](./channel.html) | 20 | [Lab 2](../lab2.html) | 스튜디오 밖에서 열어 보기. 추천 프롬프트가 보이는 자리 |
| [에이전트가 에이전트를 부른다](./connected-agent.html) | 25 | [Lab 2](../lab2.html)·[Lab 6](../lab6.html) | 잘 만든 에이전트를 도구처럼 부르기 |

{: .note }
**「에이전트 안에서 일어나는 일」은 세 부분이 따로 놉니다.** 1부(RAG·인덱싱)는 [Lab 2](../lab2.html) 17번의 **인덱싱 대기 시간에 읽는 자리**라 추가 시간이 들지 않습니다. 2부(토큰·비용)는 토크나이저를 직접 돌려 보는 15분 실습이고, 3부(문서 준비)는 10분이면 읽습니다. 셋을 따로 꺼내 써도 됩니다.

{: .warning }
**「모델을 바꾸면」 부록은 끝나고 반드시 되돌려 놓으세요.** 모델과 지침을 바꾼 채로 두면 이어지는 랩이 다른 조건에서 돌아갑니다. 되돌릴 지침 원문은 각 랩의 「여기까지의 지침」에 있습니다.
